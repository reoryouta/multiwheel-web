# Onest

Unmodified variable WOFF2 subsets from the official Google Fonts service,
downloaded on 2026-11-19. Both files contain the normal weight range 100–900.
The Cyrillic and Latin subsets cover the site's Russian and English text.
The site serves these files locally and makes no Google Fonts requests.

- Family: https://fonts.google.com/specimen/Onest
- Upstream: https://github.com/simpals/onest
- Distribution metadata: https://github.com/google/fonts/tree/main/ofl/onest
- CSS source: https://fonts.googleapis.com/css2?family=Onest:wght@100..900&display=swap
- Cyrillic: https://fonts.gstatic.com/s/onest/v11/gNMKW3F-SZuj7xmb-HY6EQ.woff2
- Latin: https://fonts.gstatic.com/s/onest/v11/gNMKW3F-SZuj7xmf-HY.woff2

The original SIL Open Font License 1.1 is included in `OFL.txt`.
